## 自然会话验收入口

```powershell
./scripts/test.ps1 -Suite SessionExpiry
```

此套件只在通过实际 `_test` 库名检查后创建一个随机会员，验证实际 TTL 为 7200 秒。最后一次受保护请求后不再访问该 Session；独立 Redis 连接只读 TTL，不删除、缩短或刷新期限。使用单调时钟等待至少 7205 秒，再验证身份和订单接口 401，并用 Chromium 打开订单页，检查重新登录及安全返回地址。默认 All 不自动引入两小时等待。

Cookie、密码、验证码和 Session 编号只留进程内存，不写日志。私有进度和最终结果位于 `.tools/test/session-expiry-{progress,result}.json`；页面证据为不含输入的登录截图。可观察进度文件，但不要用页面或请求访问目标 Session，否则测试明确失败。

本次集中运行在同一受保护 Test 生命周期内，先开始自然闲置，再串行执行独立的 All、Diagnostics 和 Browser；目标会员不参与这些请求。自然失效完成后才执行会暂停/恢复 Redis 的 Test Recovery。环境生命周期不并行，失败也恢复原模式。
