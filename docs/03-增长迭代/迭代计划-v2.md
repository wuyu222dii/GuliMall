## 目标与边界

管理员上传图片、录入双 SKU、采购入库、上架 → 会员开发验证码注册和登录 → 搜索、购物车、下单锁库 → 明确标识的模拟付款 → 库存结算 → 发货与收货。

身份、金额、数据库、库存、Session、消息和本地图片继续真实处理。支付使用官方 SDK 协议和 RSA2 通知，不通过前端或额外接口直接标记订单已支付。短信只有开发实现。不开公网，不接真实支付宝、短信或 OSS，不开发退款、营销、角色权限、报表，不升级 Java 8 / Boot 2.1.8。

## 日常使用与恢复

运行 `./scripts/simulation.ps1 Start`，浏览器访问 http://127.0.0.1:8080；Status 检查就绪，Stop 保留数据、基础设施可继续运行。首次工具、数据库和构建见 [开发说明](../DEVELOPMENT.md)，已有数据不要重跑初始化。

台账 `.data/simulation/payment/trades.json` 与匹配密钥 `.tools/simulation/payment-config.json` 分开私有保管。`backup.ps1 -Environment Demo` 完成后恢复原模式；恢复先在全新实例核对，不覆盖演示库。命令及两套演示见 [模拟手册](../SIMULATION.md) 和 [备份恢复](../RUNBOOK.md)。
