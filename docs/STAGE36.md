## 最小修复及行为边界

- 地址未知状态同时冻结正文、默认勾选和提交按钮，保留原提交内容；刷新地址列表只读取，不重发创建。把“已核对，放弃本次表单”放到禁用 fieldset 外，核对后可以明确结束。
- 共享 `useUnsavedForm` 将未保存和写入忙态同时纳入站内导航、退出和原生刷新保护；显式传入 `changed=false` 也不能绕过忙态。请求处理中，确认离开按钮不可用；取消对话框只继续原页面，不取消或重发请求。
- 干净保存完成后，原先阻塞的离开/退出不会自动执行；上传成功产生未保存图片地址时，继续按脏表单确认。只读加载与空闲干净表单不误拦。
- 基础资料保存/删除得到确认后，以 `loading` 管理后续资料读取，结束写入 `busy`；输入和重复写入仍受现有门禁约束，列表读取不延长写入离开保护。
- 复用原保护的地址、基础资料、仓库/采购、商品编辑和物流表单调用；不新增框架、数据库字段或业务接口，不改变订单状态机、期限和提交令牌。

地址正文仅在当前页面内存保留，不写 localStorage/sessionStorage。明确接受浏览器重新加载或离开后，该内存表单会丢失，仍需读取服务端列表人工核对；本阶段不提供地址持久幂等或精确创建查询，不能将此保护解释为跨刷新防重。保存后定位属于下一阶段。

新增 `scripts/browser/form-boundaries.spec.mjs`，Chromium/Edge 各三项，串行复用现有 Browser 入口和真实 Test 依赖：
