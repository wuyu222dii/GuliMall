## 后续固定边界

浏览器接口统一 `/api`，管理接口 `/api/admin`；服务端验证身份和数据归属，内部 Feign 接口不开放给浏览器，保留 R / PageUtils。

真实短信、OSS、技术栈升级后置；本轮不扩展秒杀、自动退款售后、多商户、多支付渠道、完整角色权限或高可用集群。
